# Wotix – Features

## Overview

Wotix is a feature-rich e-commerce platform designed to provide a complete online shopping experience for customers while offering administrators powerful tools for inventory, order, and business management.

---

# Customer Features

## Authentication & Account Management

Customers can securely create and manage their accounts through:

- User Registration
- Email OTP Verification
- Email & Password Login
- Google OAuth Login
- Forgot Password
- Password Reset
- Change Password
- Profile Management
- Logout

---

## Product Discovery

Customers can easily discover products using:

- Product Listing
- Product Details
- Product Search
- Category Filtering
- Product Sorting
- Pagination
- Product Recommendations

---

## Shopping Cart

The shopping cart provides:

- Add Product to Cart
- Remove Product
- Update Product Quantity
- Automatic Price Calculation
- Offer Discount Calculation
- Cart Summary
- Clear Cart

---

## Wishlist

Customers can:

- Add Products to Wishlist
- Remove Products from Wishlist
- View Saved Products

---

## Address Management

Customers can manage multiple delivery addresses by:

- Adding New Address
- Editing Existing Address
- Deleting Address
- Selecting Default Address

---

## Checkout

Checkout supports:

- Address Selection
- Order Summary
- Coupon Application
- Offer Discount Calculation
- Payment Method Selection

---

## Payment Options

The platform supports multiple payment methods:

- Cash on Delivery (COD)
- Razorpay Online Payment
- Wallet Payment

All online payments are verified before order confirmation.

---

## Order Management

Customers can:

- Place Orders
- View Order History
- Track Order Status
- View Order Details
- Retry Failed Payments
- Download PDF Invoice

---

## Order Cancellation

Customers can:

- Cancel Entire Orders
- Cancel Individual Products
- Receive Wallet Refunds (where applicable)

---

## Return Management

Customers can:

- Submit Return Requests
- Track Return Status
- Receive Wallet Refunds after approval

---

## Wallet

Customers have access to a digital wallet featuring:

- Wallet Balance
- Transaction History
- Refund Credits
- Wallet Payments

---

## Notifications

Real-time notifications inform customers about:

- Order Status Updates
- Return Approval
- Return Rejection
- Order Cancellation
- Delivery Updates

---

# Security Features

The application includes several security mechanisms:

- JWT Authentication
- Google OAuth Authentication
- Role-Based Authorization
- Protected Routes
- Password Hashing using bcrypt
- HTTP-only Cookies
- Secure HTTP Headers using Helmet

---

# Business Features

The platform implements several business workflows including:

- Product Offer System
- Coupon Discount System
- Automatic Price Calculation
- Wallet Refund System
- Order Lifecycle Management
- Return Approval Workflow
- Sales Reporting
- Invoice Generation

---

# Real-Time Features

Using Socket.IO, the application provides:

- Instant Notifications
- Real-Time Order Updates
- Return Request Notifications
- Delivery Status Notifications

---

# Summary

Wotix combines customer shopping features, secure payment processing, wallet management, administrative tools, reporting, and real-time communication into a complete e-commerce platform. The application is designed to support the complete lifecycle of online shopping—from product discovery to payment, order fulfillment, returns, refunds, and business analytics.
